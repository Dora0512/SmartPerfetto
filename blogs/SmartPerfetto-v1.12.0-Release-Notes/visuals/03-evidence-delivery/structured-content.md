# Structured content

- Main flow:
  1. User request.
  2. Plan + SQL/Skill/source tools.
  3. Producer-bound evidence ledger.
  4. Candidate conclusion + native claim declarations.
  5. Bounded no-tool semantic review.
  6. Claim states: verified / partial / unchecked / failed.
- Fan-out surfaces: Web, CLI, HTML report, snapshot, JSON/NDJSON.
- Side annotations: body preserved; reason codes; status + attempts; transient-only retry.
- Visual distinction: candidate body and verification status are adjacent but separate.
