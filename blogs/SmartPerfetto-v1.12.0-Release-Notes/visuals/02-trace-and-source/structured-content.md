# Structured content

- Theme: Dual Trace + authorized source.
- Left upper lane: baseline Trace and comparison Trace, independent upload/replace, explicit swap, reload restore.
- Left lower lane: selected source folder, bounded preview, on-demand search/read, optional index.
- Guard rail: source selection + provider consent + Git provenance + content fingerprint.
- Center: analysis workspace with pinned run identity.
- Right: evidence with trace side, selection, process/thread identity, CodeRef provenance, and report/snapshot output.
- Connections: orthogonal arrows from both lanes into the workspace and from the workspace into evidence.
