Discover scene methodology with no arguments (current-scene detail catalog),
or read a complete detail using a detailRef from scene_strategy_details or the
catalog. A plan is not required. Optional scene selects another scene's catalog;
detailId selects a detail in that scene. Guidance is subordinate to the current
turn's scope, evidence access and authorization; legacy fixed tool sequences do
not override them. This tool does not collect trace evidence or satisfy expectedCalls.
